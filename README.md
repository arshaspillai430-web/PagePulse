# Page Pulse 

Page Pulse is a web-based URL auditing tool that analyzes a webpage and generates a report containing important page metrics.

## Features

- Check HTTP status code
- Measure response time
- Extract page title
- Extract meta description
- Count H1 headings
- Detect images missing alt attributes
- Estimate webpage word count
- Handles invalid URLs, unreachable websites, and non-HTML responses
